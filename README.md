## Installing PyTorch

1. Check if you have an NVIDIA GPU.
2. Install [CUDA Toolkit](https://developer.nvidia.com/cuda/toolkit)
3. Check CUDA Version by running `nvidia-smi`
4. Install [PyTorch](https://pytorch.org/get-started/locally/) libraries

For Windows use `pip`, not `pip3`

## Installing Libraries

```bash
pip install -r requirements.txt
```

## Run the Script

```bash
python <folder>/<file>.py
```
